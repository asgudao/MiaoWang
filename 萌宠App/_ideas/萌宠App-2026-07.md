# 萌宠 App - 原始 Idea

## 一句话想法

> "我想做一个手机端的萌宠相关的软件，目前主要的服务对象应该是猫狗。"

## 原始需求要点（用户原话）

- 养宠注意事项（疫苗等）
- 不同品种的猫狗对应提示（如"一个月剪一次指甲"）
- VIP 会员订阅（普通 1 猫 1 狗，会员多只）
- AI Agent（必须会员才能用，非会员试用 3-4 次，需要图片识别）
- 萌宠社区（分享 + 交流）

## 决策对话中的关键澄清

| 问题 | 用户选择 |
|---|---|
| 平台 | iOS + Android 跨端 |
| 前端 | **uni-app**（vibe coding 友好） |
| 后端 | Spring Boot |
| AI 模型 | 国内多模态大模型 |
| 知识库来源 | LLM 生成 + 人工审校 |
| MVP 切分 | 知识 + 品种提醒 + 限只数订阅 |
| 变现 | 订阅 + AI 按调用付费 + 信息流广告 |

## 已被纠正 / 作废的内容（避免再问）

- ❌ 完成时间、团队人数、MVP 砍什么、预算 —— LLM 不主动规划可行性
- ❌ 求职定位相关问题 —— 用户的本意是"开发并赚钱"，非秋招导向

## 待回答的问题

- [ ] 订阅定价（月 / 季 / 年具体金额）
- [ ] 会员可养宠物数量上限
- [ ] 试用 3-4 次的计次粒度（终身 / 每月 / 每日）
- [ ] 三个国内多模态模型具体选哪个
- [ ] 域名 / 服务器 / 备案
