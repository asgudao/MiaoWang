# 萌宠 App - 项目概览

## 一句话愿景

面向猫狗养宠人群的手机端萌宠 App，融合**养宠知识**、**品种化护理提醒**、**订阅会员**、**AI Agent**（后续）、**社区**（后续）。

## 产品形态

- **平台**：iOS + Android（uni-app 跨端）
- **服务对象**：猫、狗（初期）
- **产品定位**：通用养宠人群，UI 不限人群
- **目的**：开发并赚钱（非秋招导向）

## 商业模式

| 模式 | 时机 | 说明 |
|---|---|---|
| 会员订阅（养宠数量限制） | MVP | 普通用户 1 猫 1 狗；会员可多养 |
| AI 按调用付费 | Phase 2 | 非会员可免费试用 3-4 次，超限按调用/包月付费 |
| 信息流广告 | Phase 3 | 首页 / 社区信息流广告位 |

> 不含自营/联营商城（暂不考虑）。

## 核心壁垒

- 养宠知识 + 品种化护理提醒（疫苗 / 驱虫 / 剪指甲 / 体检周期）
- 国内多模态大模型驱动的 AI Agent
- 萌宠社区（UGC + 互动）

## 阶段路线（思路层）

```
MVP (思路层)            Phase 2                  Phase 3
├── 知识库             ├── AI Agent 4 能力        ├── 社区（UGC）
├── 品种提醒           ├── AI 按调用付费          ├── 信息流广告
├── 用户/宠物管理       └── 推送通知               └── 商城（待定）
├── 限只数订阅
└── 基础 UI
```
