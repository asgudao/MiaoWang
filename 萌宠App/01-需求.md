# 萌宠 App - 需求清单

## MVP 范围（思路层）

> 思路层面的产品切分。具体执行节奏由用户决定。

### 1. 养宠知识库

- 猫狗通用护理知识（疫苗、驱虫、体检、常见疾病）
- **数据来源**：LLM 批量生成 + 人工审校
- **展示**：分类列表 + 搜索 + 详情页

### 2. 品种化护理提醒

- 常见猫狗品种库
- 每个品种关联护理周期（疫苗、驱虫、剪指甲、洗澡、体检）
- 用户设置宠物时绑定品种 → 自动生成提醒计划
- 推送通知（本地 / uniPush）

### 3. 用户 / 宠物管理

- 用户注册 / 登录（手机号 + 微信 / Apple ID）
- 宠物档案：品种、年龄、体重、照片
- 多宠物支持：普通用户 1 猫 1 狗；会员多只

### 4. 限只数订阅

- 普通：可养 1 只猫 + 1 只狗
- 会员：可养 N 只（具体数量 / 定价由用户定）
- 订阅档位：月 / 季 / 年

### 5. 基础 UI

- 首页（知识流 + 今日提醒）
- 我的宠物
- 知识库
- 订阅中心
- 我的

## Phase 2：AI Agent（接口预留，先不做）

接口层占位，后端留 SDK 接入点。

### 能力清单

- **品种识别**：拍照 → 识别品种 → 输出养护建议
- **健康问答**：文字问答（结合知识库 RAG）
- **症状解读**：图片 / 视频 → 可能疾病方向
- **个性化推荐**：宠物用品 / 驱虫药 / 名字推荐

### 模型选型

- **国内多模态大模型**（性价比 + 合规）
- 候选：智谱 GLM-4V / 通义 Qwen-VL / 豆包视觉
- 性价比优先，按调用量阶梯定价

### 试用策略

- 非会员：试用 3-4 次（粒度待定：终身 / 每月 / 每日）
- 会员：无限次 / 大配额
- 超出按调用付费

## Phase 3：社区 + 广告

- 萌宠社区（UGC 帖子 / 评论 / 点赞）
- 信息流广告位（首页 + 社区）

## 不做（明确）

- 自营 / 联营宠物用品商城（暂无供应链计划）
- 多语言 / 海外用户
- 兽医在线问诊（合规风险高）
